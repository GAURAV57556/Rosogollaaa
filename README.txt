OUR LITTLE UNIVERSE — ROSOGOLLA

All website files and all six photos are together in this one folder.

FOLDER CONTENTS
- index.html
- style.css
- script.js
- README.txt
- memory-1.jpg through memory-6.jpg

PREVIEW
Double-click index.html to open the website in a browser.

GITHUB PAGES
1. Create a new GitHub repository.
2. Upload ALL files from this folder directly into the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select main and /(root), then Save.

Keep all six JPG photos beside index.html. Do not put them in a separate folder or rename them unless you also update index.html.
